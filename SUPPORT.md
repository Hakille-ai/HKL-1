## 🐛 Bug Reports

If you've found a bug:

1. **Search** [existing issues](https://github.com/Hakille-ai/HKL-1/issues) to avoid duplicates
2. **Open a bug report** with:
   - HKL-1 version (commit hash)
   - Platform (host OS, MCU target, BSP feature)
   - Steps to reproduce
   - Expected vs actual behavior
   - `cargo test --lib` output (if applicable)

## 💡 Feature Requests

Have an idea for HKL-1?

1. **Search** [existing issues](https://github.com/Hakille-ai/HKL-1/issues) and [discussions](https://github.com/Hakille-ai/HKL-1/discussions)
2. **Open a feature request** with:
   - Clear description of the problem
   - Proposed solution
   - Alternative approaches considered
   - Is it `#![no_std]` compatible?
